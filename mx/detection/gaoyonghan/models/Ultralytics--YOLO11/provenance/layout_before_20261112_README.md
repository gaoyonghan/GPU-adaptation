# Ultralytics/YOLO11

Run `python inference/run.py` from this model folder. The native script and its support files are in `inference/native/`; format conversion and scoring entry points are in `evaluation/`. Weights are in `weights/`, and datasets are in the project's sibling `dataset/` directory. Python dependencies are listed in `requirements.txt` and `inference/environment.json`. The recorded commands and source metadata are in `provenance/`. No full run of this reorganized folder has been performed.
