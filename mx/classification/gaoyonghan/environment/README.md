在镜像内进入对应模型目录后执行（复跑时换一个新的输出目录名）：

```bash
source /opt/model-envs/e33/bin/activate
python inference.py --phase full --output-root result/full_001
python /project/classification/evaluate.py --run-dir "$PWD/result/full_001"
```
